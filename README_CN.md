## Dynamis 是什么？

Dynamis 是一个完全由 GPU 驱动的面向数据的通用物理引擎，使用 rust 编写。它提供了最好的性能与灵活性。

## 特性

- **GPU 驱动** —— 整个模拟都在 GPU 上运行以获得最好的性能。
- **数据驱动** —— 灵活构建大规模场景。
- **跨平台** —— 支持桌面、移动端和 Web。
